Keyboard

Branchboard is built to be driven from the keys — the mouse is optional.

Growing

  • Add child Tab
  • Add sibling Enter
  • Add sibling above Ctrl + Enter
  • Add a parent above Alt + Enter
  • New tree M
  • Edit text F2
  • Line break while editing Shift + Enter
  • Bold / italic / underline Ctrl + B / I / U
  • Emoji into the words Ctrl + E
  • Delete Delete
  • Duplicate Ctrl + D
  • Detach as new tree D

Restructuring

  • Indent (tuck under sibling) Ctrl + Alt + ]
  • Outdent Ctrl + Alt + [
  • Copy branch Ctrl + C
  • Cut branch Ctrl + X
  • Paste (an outline works too) Ctrl + V

Moving around

  • Walk the tree ↑ ↓ ← →
  • Collapse / expand Ctrl + / or C
  • Select several Shift + Click
  • Select all Ctrl + A
  • Find in board Ctrl + F
  • Pan the canvas Space + drag

View & style

  • Zoom in / out = / -
  • Zoom to 100% 0
  • Zoom to content 1
  • Zoom to selection 2
  • Colour the branch Shift + 1…8
  • Icon on a node Shift + X
  • Link on a node Ctrl + Shift + U
  • Undo / redo Ctrl + Z
